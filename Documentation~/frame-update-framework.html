GFramework Unity 通用运行时框架

让 Unity 项目的公共运行时能力可组合、可管理。

GFramework 是一套基于 C# 的 Unity 框架。它统一组织每帧更新、输入、物理、资源、场景、音频、对象池、配置存档、应用生命周期和 UI，让游戏业务专注于玩法规则与内容。

Unity 2022.3 · 模块化 · 显式生命周期

系统作用

统一更新

把输入、逻辑、物理、表现等任务接入统一调度器，集中处理阶段、频率、优先级和时间。

控制暂停

按更新组暂停或恢复局部系统，不必依赖全局 Time.timeScale。

管理生命周期

用作用域、句柄和异步关闭流程管理场景、模块、资源和 UI 的创建与释放。

隔离模块依赖

核心逻辑与 Unity 适配层分离，各模块通过接口组合，避免业务脚本直接互相调用。

统一资源流程

封装资源加载、场景切换、对象池和音频播放的所有权、取消和释放。

接通 UI

提供面板管理、MVVM ViewModel、控件绑定、命令状态和主线程通知。

运行方式

应用启动时创建运行时和模块服务；Unity 宿主提供更新节拍；业务对象注册到对应循环和作用域；暂停、切场景或退出时按所有权逆序清理。

模块分工

模块作用
FrameUpdate循环、阶段、调度频率、分组暂停、作用域和诊断。
Application应用运行时、模块初始化、关闭和失败回滚。
Input / Physics输入快照、动作上下文、固定步输入和物理接入。
ResLoad / Scene / Pool资源租约、Addressables 场景、实例池和异步释放。
Audio / Config音频服务、混音总线、配置读取、版本迁移和存档。
UI面板栈、模态关闭、MVVM、绑定、命令和视图生命周期。

框架边界

框架负责公共运行时机制、调度、状态和资源所有权；游戏项目负责玩法规则、关卡内容、网络协议、具体 UI 视觉和业务数据。
